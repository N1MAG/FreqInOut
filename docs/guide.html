FreqInOut User Guide

Current version: 1.0.8

This guide describes every tab, button, field, and function in FreqInOut. Times are stored in UTC; the "Showing: Local/UTC" toggle only changes what you see.

Responsibility notice: FreqInOut assists licensed amateur operators by coordinating complex radio software and schedules. It assumes you follow applicable band plans and regulations. Disabling safeguards (for example, scheduling) can let you tune outside legal allocations. You are solely responsible for compliant operation; the authors and contributors are not liable for misuse.

Quick Start

Purpose: Get a first successful setup and map display quickly.

  1. Start in Settings: Open Settings and enter your callsign/name/state/grid, select Frequency Control, set JS8Call DIRECTED.TXT, and set message folders. Click Save Settings so the other tabs pick up your changes.
  2. Create Operating Groups: Add your go-to frequencies in Operating Groups. These drive the HF Schedule, Net Schedule, and the QSY dropdowns.
  3. Build schedules: Use HF Schedule for routine operating blocks and Net Schedule for nets. The FreqPlanner view updates from these schedules.
  4. Populate operators and JS8 traffic: Import your operator list in Operators, then return to Settings > JS8Call Settings and click Load JS8 Traffic to populate the Map and link history.
  5. Open the Map: Use the Map Layers sidebar filters and the map dropdowns to focus on the groups, regions, bands, and recency windows you care about.

Prerequisites

Purpose: Ensure required software and paths are in place before first run.

  • Install method: Packaged builds include dependencies; source installs use a Python venv and pip install -r requirements.txt.
  • Python: 3.9-3.12 for source installs.
  • Debian/Ubuntu: Install python3 python3-venv python3-pip libxcb-cursor0 libxcb-xinerama0, then create a venv and install requirements.
  • Radio software: Install FLRig if you want rig control, JS8Call for JS8 features, and FLDigi/FLMsg/FLAmp if you plan to run FLDigi nets or view NBEMS messages.
  • Paths you will need: JS8Call DIRECTED.TXT (and its folder), and the VarAC/FLMSG/FLAMP folders used by the Messages tab.

FreqPlanner Tab

Purpose: A read-only 24-hour view of HF and Net schedules.

  1. Header clocks: UTC and Local times update live.
  2. Showing: UTC/Local: Toggle how the time columns are labeled; schedule data is still stored in UTC.
  3. Band legend: The legend above the grid shows the color mapping for bands.
  4. Planner table: Columns are UTC Hour, Local Time (TZ), and Sunday through Saturday. The table is read-only and not sortable.

Messages Tab

Purpose: View and manage FLDigi/FLMsg/FLAmp/VarAC files and JS8 inbox messages.

  1. Scan every: Dropdown for 1/15/30/60 minutes; controls file folder rescan intervals. JS8Call messages refresh automatically at short intervals.
  2. Refresh Now: Forces an immediate refresh of file-based messages and JS8 inbox data.
  3. Export to PDF: Exports the currently viewed file-based message.
  4. Pending JS8 MSGs: Table columns are Callsign, Msg ID, Last Seen, Status, Actions. Actions include Get (send a JS8 QUERY MSG) and Mark Retrieved (clears the pending state; can also mark JS8Call inbox rows READ if enabled in Settings).
  5. Filters row: Dropdown filters for MSG Type, Status, From, and To; a Search box for free-text; and Clear Filters to reset.
  6. Messages table: Columns are MSG Type, Status, From, To, RCV_DT, Message Title, and Actions. Actions show View for JS8 messages or View | Delete for file-based messages.
  7. Sorting: Click headers to sort by MSG Type, Status, From, To, RCV_DT, or Message Title (Actions is not sortable).
  8. Reader panel: The lower pane shows the selected message and stays open while you review entries.

FLDigi NCS Tab

Purpose: Manage FLDigi net check-ins and logs.

  1. Header clocks: UTC and Local update live at the top.
  2. Next Scheduled Net: The banner shows the next net and current band; it also reflects scheduler pause state.
  3. Role: Dropdown with NCS/ANCS/JOINER, which affects how your own entry is tagged when starting a net.
  4. Net Name: Editable dropdown with schedule-driven suggestions.
  5. QSY controls: QSY dropdown (Operating Groups) and QSY button. Clicking QSY changes frequency and pauses the scheduler for 30 minutes (button shows remaining time).
  6. Ad Hoc Net: Creates a timestamped net name and starts the net.
  7. Operator Lookup/Add: Search field that auto-fills known operators; use Tab/Enter to move through Add buttons.
  8. Add to Main / Add to New/Late: Buttons that insert the lookup line into the appropriate pane.
  9. Compare NCS Lists: Opens a dialog with Compare, Copy Missing, and Close to reconcile local check-ins against an NCS list.
  10. Copy buttons: Copy the full Main or New/Late text to the clipboard.
  11. Main Check-in Log: Editable text area for primary check-ins.
  12. New/Late Check-ins: Editable text area for late or follow-up entries.
  13. Start Net: Begins the net session.
  14. Save Check-ins: Writes both panes to the configured check-in files and refreshes operator history.
  15. Merge Check-ins: Moves New/Late entries into Main and clears New/Late.
  16. End Net: Saves and closes the net; can auto-end if a scheduled frequency change occurs and the scheduler is not paused. Check-ins are saved to Operator History and the check-in counter is incremented.

JS8 NCS Tab

Purpose: Manage JS8Call net check-ins, ACKs, and spotter forms.

  1. Header clocks: UTC and Local update live at the top.
  2. Role: Dropdown with NCS/ANCS.
  3. Net Name: Text field with schedule-based auto-complete.
  4. Refresh (sec): Spinbox for JS8 polling interval (5-300 seconds).
  5. Set Group: Button plus group field (use @GROUP format); required to start a net.
  6. Set Expect Query: Button plus Spotter dropdown to choose a form (F!###). The dropdown is disabled if no forms are found.
  7. QSY controls: QSY dropdown (Operating Groups) and QSY button. QSY pauses the scheduler for 30 minutes.
  8. Ad Hoc Net: Starts a net with a timestamped name.
  9. Check-in Filter: Dropdown with F!103 / F!104, Any Spotter, and All Callsigns.
  10. Check-ins table: Columns are CALLSIGN, NAME, ST, GRID, REGION, MODE, SNR, OFFSET, STATUS, and Actions.
  11. Delete action: The Actions column shows Delete only when a net is in progress and the filter is All Callsigns.
  12. Start Net: Clears and begins monitoring.
  13. ACK GROUP / ACK CALLSIGN: Sends group or selected callsign acknowledgments.
  14. E? GROUP / E? Callsign: Sends a spotter form query to the group or selected callsign.
  15. Save Checkins: Saves this net’s check-ins to the DB and updates Operators.
  16. End Net: Ends the net and writes a net log file in a net_logs folder next to DIRECTED.TXT.

Operators Tab

Purpose: Maintain operator records used by maps and nets.

  1. Search: Text box that filters by any column.
  2. Refresh: Reloads operator data from the DB.
  3. Import/Export...: Menu with Import CSV... and Export CSV....
  4. Manage Operators: Menu with Add Operator..., Edit Selected...(bulk trust update), and Delete Selected....
  5. Select All: Checks every row for bulk export or edits.
  6. Filter by: Dropdown with All, Untrusted, and any discovered group names.
  7. Operators table: Columns are Selected checkbox, Callsign, Name, State, Grid, Group 1, Group 2, Group 3, Group Role, First Seen, Last Seen, Trusted, and Check-ins. The table is not sortable.
  8. Add/Edit dialog fields: Callsign, Name, State, Grid, Group 1/2/3, Group Role, First Seen, Last Seen, Trusted ("do I trust their reports?").

Map Tab

Purpose: Visualize operators, grids, and JS8 traffic links.

  1. Map link controls row: Top row includes Paths (Off/My Station/All), Group, Region, Band, Recency (Any, 15m, 30m, 1h, 3h, 6h, 12h, 24h, 7d), Paths to (editable callsign), and Refresh Links.
  2. Map view: Requires Qt WebEngine; if unavailable, a disabled message is shown.
  3. Map Layers (sidebar): Only visible when Map is active. Checkboxes for Callsigns, States, Cities, Grids, and Regions plus a City Pop. dropdown (1M+, 750k+, 500k+, 250k+, 100k+, 75k+, 50k+, 25k+, 10k+, 5k+, <5k).
  4. Paths to: Use this to focus link highlights on paths that reach a specific callsign.
  5. Refresh Links: Forces JS8 log ingest and redraw.

HF Schedule Tab

Purpose: Plan routine operating blocks.

  1. Header clocks: UTC and Local update live.
  2. Showing: UTC/Local: Toggle the time display only.
  3. QSY controls: QSY dropdown (Operating Groups) and QSY button. QSY pauses the scheduler for 30 minutes.
  4. Schedule table: Columns are Selected, Day, Group Name, Mode, Band, Freq (MHz), Start, End, Auto-Tune. The table is not sortable.
  5. Add Row: Inserts a new schedule row.
  6. Delete Selected: Removes checked rows.
  7. Save HF Schedule: Saves to the database and refreshes FreqPlanner.
  8. Export HF Schedule: Exports JSON in UTC.

Net Schedule Tab

Purpose: Define net windows and how they repeat.

  1. Header clocks: UTC and Local update live.
  2. Showing: UTC/Local: Toggle the time display only.
  3. Schedule table: Columns are Selected, Day (Local or UTC), Recurrence, Group Name, Mode, Band, Freq (MHz), Start, End, Early (min), Net Name, Auto-Tune. The table is not sortable.
  4. Add Row: Inserts a new schedule row.
  5. Delete Selected: Removes checked rows.
  6. Export Net Schedule: Exports JSON in UTC.
  7. Import Net Schedule: Imports JSON (interpreted as UTC).
  8. Save Net Schedule: Saves to the database and refreshes FreqPlanner.

Peer Schedules Tab

Purpose: Track schedules imported from other operators.

  1. Import Schedule: Loads a peer HF schedule JSON (UTC).
  2. Refresh: Reloads the list from the database.
  3. Delete: Dropdown for callsigns plus Delete Schedule to remove a single peer schedule.
  4. Clear All: Removes all imported peer schedules.
  5. Filters: Callsign dropdown, Region dropdown (R01-R10), Group dropdown, and Search field.
  6. Peer schedule table: Columns are CALLSIGN, NAME, STATE, GROUPS, DAY (UTC), START UTC, END UTC, BAND, MODE, FREQ. The table is not sortable.

Settings Tab

Purpose: Configure operator details, scheduler behavior, and integrations.

Quick links: Operator Information | FreqInOut Settings | Operating Status | Operating Groups | JS8Call Settings | Radio Software | Save Settings

Operator Information

  • Header clocks: UTC and Local update live.
  • Callsign / Name / State / Grid 6: Used in net control, operator history, and map placement.

FreqInOut Settings

  • Theme: Light or Dark.
  • Frequency Control: FLRig, JS8Call, or Manual (no rig commands).
  • Use FreqInOut Scheduler: Master enable for schedule-driven changes; disables QSY when off.
  • Schedule Mode: Normal (apply on schedule only), Loose (prompt to reapply when off schedule), Strict (periodic resync). Off-schedule prompts offer Yes, Suspend, or Ignore.

Operating Status

  • Status LEDs: JS8, FLRig, FLDigi, FLMsg, FLAmp, VarAC, JS8Spotter, CommStat.
  • Color meaning: Green running, gray stopped, yellow running but unreachable.

Operating Groups

  • Section behavior: Collapsible header toggles open/closed state.
  • Add Group: Opens a dialog to define Group Name, Mode, Band, Frequency, VFO, FLDigi Starting Mode, FLDigi Starting Offset (Hz), and Auto-Tune.
  • Edit Selected: Edits the checked row (one at a time).
  • Delete Selected: Removes checked rows.
  • Operating Groups table: Columns are Selected, Group, Mode, Band, Freq (MHz), VFO, FLDigi Starting Mode, FLDigi Starting Offset, Auto-Tune.

JS8Call Settings

  • Section behavior: Collapsible header toggles open/closed state.
  • TCP Port: Must match JS8Call configuration.
  • Offset (Hz): Applied on startup and on schedule changes.
  • Mark JS8Call MSG Read?: Syncs Message Viewer Mark Retrieved to JS8Call inbox READ state.
  • JS8Call DIRECTED.TXT: Path field plus Browse button.
  • JS8Spotter forms: Path field plus Browse button (MCF###.txt forms).
  • Load JS8 Traffic: Ingests DIRECTED.TXT/ALL.TXT into Map and Operators.

Radio Software

  • Section behavior: Collapsible header toggles open/closed state.
  • Program rows: FLRig, FLDigi, FLMsg, and FLAmp each have a checkbox, path field, and Browse button.
  • FLRig XMLRPC Port: Port field under the FLRig row.
  • Check-in File Path: FLDigi check-in folder plus Browse.
  • ICS/Messages: FLMsg folder plus Browse.
  • FLAMP/rx: FLAmp folder plus Browse.
  • VarAC: Read-only status/path field and VarAC Incoming Files path plus Browse.
  • Launch Selected: Launches checked programs that are not already running.
  • Check-in Log Paths: Copy Main and Copy New/Late buttons copy full file paths to the clipboard.

Save Settings

  • Save Settings: Persists all settings and refreshes dependent tabs.
  • Auto-save on exit: Settings are also saved when the app closes.

Logs Tab

Purpose: View and filter application logs.

  1. Refresh: Reloads the log view (auto-refresh runs every 1.5 seconds).
  2. Clear: Clears the on-screen view only.
  3. Search: Prompts for a keyword and filters matches.
  4. Open Log: Opens the current log file in your OS viewer.
  5. Font: Spinbox for log font size.
  6. Level: Dropdown with DISABLED, ERROR, WARNING, INFO, DEBUG, ALL. This sets the global log level.
  7. Log file label: Shows the active log file path.
  8. Sidebar indicator: When log level is not DISABLED, the Logs button changes to Logs Enabled and is highlighted in warning color.

Help Tab

Purpose: Read this guide and export it.

  • Table of Contents: Left-side list of H1-H3 headings for quick navigation.
  • Guide viewer: Right-side browser that renders docs/guide.html.
  • Export to PDF: Saves the guide as a PDF file.

Troubleshooting and Tips

Purpose: Common fixes and operational tips.

  • Scheduler not changing frequency: Verify Use FreqInOut Scheduler is on, the pause timer has expired, and Operating Groups include valid band/mode/frequency.
  • JS8 NCS will not start: Check that callsign, Net Name, Group, and DIRECTED.TXT are set in Settings.
  • Messages list is empty: Confirm Message Paths in Settings and click Refresh Now.
  • Map shows no links: Use Load JS8 Traffic in Settings and confirm DIRECTED.TXT is valid.
  • Logs too large: Keep level at DISABLED or INFO for daily use; raise to DEBUG or ALL only for troubleshooting.

Database Tools

Purpose: Inspect or clean the SQLite databases used by FreqInOut.

  • db_tools.py: Simple CLI to list, show, export, and truncate tables. Examples: python tools/db_tools.py --list-dbs, python tools/db_tools.py --table operator_checkins --table-show.
  • db_admin.py: Admin CLI to initialize or truncate full tables (settings + nets). Examples: python tools/db_admin.py --init all, python tools/db_admin.py --truncate nets_all --yes.
  • js8_links_check.py: Quick inspection of JS8 link ingestion. Example: python tools/js8_links_check.py --limit 20.
  • dedupe_operator_groups.py: Cleanup tool for legacy duplicate group assignments in operator records. Run a dry run with python tools/dedupe_operator_groups.py, then apply with python tools/dedupe_operator_groups.py --apply.
  • Database locations: Settings live in config/freqinout.db. Operator and net data live in config/freqinout_nets.db.
