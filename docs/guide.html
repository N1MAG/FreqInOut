FreqInOut User Guide

Current version: 1.0.0

This guide describes every tab, button, field, and function in FreqInOut. Times are stored in UTC; the "Showing: Local/UTC" toggle only changes what you see.

Responsibility notice: FreqInOut assists licensed amateur operators by coordinating complex radio software and schedules. It assumes you follow applicable band plans and regulations. Disabling safeguards (for example, scheduling) can let you tune outside legal allocations. You are solely responsible for compliant operation; the authors and contributors are not liable for misuse.

Quick Start

  1. Start in Settings: Open Settings and enter your callsign/name/state/grid, select Frequency Control, set JS8Call DIRECTED.TXT, and set message folders. Click Save Settings so the other tabs pick up your changes. (You can return here anytime.)
  2. Create Operating Groups: Add your go-to frequencies in Operating Groups. These drive the HF Schedule, Net Schedule, and the QSY dropdowns.
  3. Build schedules: Use HF Schedule for routine operating blocks and Net Schedule for nets. The FreqPlanner view updates from these schedules.
  4. Load operators and JS8 traffic: Import your operator list in Operators, then return to Settings > JS8Call Settings and click Load JS8 Traffic to populate the Map and link history.

1. Prerequisites

  • Install method: Packaged builds include dependencies; source installs use a Python venv and pip install -r requirements.txt.
  • Python: 3.9-3.12 for source installs.
  • Debian/Ubuntu: Install python3 python3-venv python3-pip libxcb-cursor0 libxcb-xinerama0, then create a venv and install requirements.
  • Radio software: Install FLRig if you want rig control, JS8Call if you want JS8 features, and FLDigi/FLMsg/FLAmp if you plan to run FLDigi nets or view NBEMS messages.
  • Paths you will need: JS8Call DIRECTED.TXT (and its folder), and the VarAC/FLMSG/FLAMP folders used by the Messages tab.

2. Settings Tab

Back to Quick Start

Operator Information

  • Header clocks: The Settings header shows UTC and Local based on your system timezone.
  • Callsign / Name / State / Grid6: These show up in net control, operator history, and the map. A 6-character grid is used for map placement (it is more precise than a state but still privacy friendly).
  • Why it matters: Your callsign is required to send JS8 messages and to start nets; your grid helps the Map tab place your station.

Operation Settings

  • Frequency Control: Choose FLRig, JS8Call, or Manual. FLRig requires the XMLRPC port. Manual means no rig commands are sent.
  • Use Scheduler: Master enable for schedule-driven frequency changes. When off, QSY buttons are disabled and the scheduler does not send rig commands.
  • Theme: Light or Dark UI theme. Changes apply immediately after Save Settings.

JS8Call Settings

  • JS8Call API indicator: The LED shows JS8Call API status: green = reachable, yellow = running but API not reachable, gray = not running.
  • TCP Port / Offset (Hz): TCP Port must match JS8Call configuration. The Offset will be applied to JS8Call.
  • DIRECTED.TXT path: Browse to JS8Call's DIRECTED.TXT. ALL.TXT and the inbox database are inferred from the same folder. Required for JS8 NCS.
  • JS8Spotter forms: Folder that contains MCF###.txt files so spotter traffic (F!###) can be decoded in Messages and JS8 NCS. Used by JS8 NCS and Messages.
  • Mark JS8Call MSG Retrieved: When enabled, clicking Mark Retrieved in Messages will also set the JS8Call inbox row to READ.
  • Load JS8 Traffic: Ingest DIRECTED.TXT and ALL.TXT into the Map links and operator history. After running it, check Map and Operators.

Operating Groups

  • Purpose: Operating Groups are your master list of frequencies. They populate the HF Schedule, Net Schedule, and QSY dropdowns in the net control tabs.
  • Add Group: Click Add Group and enter Group, Mode, Band, Frequency, and Auto-Tune. Frequencies are validated against the band/mode ranges.
  • Edit Selected: Tick exactly one row and click Edit Selected.
  • Delete Selected: Tick one or more rows and click Delete Selected.
  • Auto-Tune: When enabled, QSY will also run a rig tune (if your rig control supports it).
  • Used by: HF Schedule, Net Schedule, FLDigi NCS, JS8 NCS, and the shared QSY / Suspend controls.

Message Paths

  • VarAC / FLMSG / FLAMP folders: These folders power the Messages tab. If you change them here, the Messages tab reads the new paths on the next refresh. Back to Messages
  • FLDigi check-in files: Set FLDigi Check-in File Path to control where FLDigi net logs are written. The read-only fields show the exact file paths and include Copy Path buttons. Back to FLDigi NCS

Radio Software

  • Program rows: Each row has a checkbox (selects the app for Launch), a status LED (running or not), and an executable path.
  • Status LED: Green means the program is running; gray means not running.
  • Launch Selected: Starts the checked programs that are not already running. This is a convenience launcher; JS8Call is managed separately.
  • Autostart note: If you have legacy autostart flags in your settings, the schedule tabs can auto-launch Digi tools when you select Digi mode. Otherwise nothing auto-launches.

Save Settings

  • Save Settings: Writes all settings and refreshes the rest of the app (QSY dropdowns, net name suggestions, map layers). Use this after changing paths or Operating Groups.
  • Auto-save on exit: Settings are also saved when the app closes, but you should still use Save Settings after major changes.

3. Scheduler and Planning

Daily Schedule Tab

  1. Start with Operating Groups: The Group/Mode/Band/Frequency fields pull from Operating Groups. If a group has multiple modes for the same band, the Mode cell becomes a dropdown.
  2. Add a row: Click Add Row, then select Day (or ALL), Group Name, Band, Mode, and VFO. Start/End are HH:MM. The Frequency cell is read-only and auto-filled from the group.
  3. Day and overnight rules: ALL applies every day. If Start is later than End, the row spans overnight into the next day.
  4. Auto-Tune: Check Auto-Tune if you want a rig tune when this row becomes active (if your rig backend supports it).
  5. Frequency validation: Band/mode ranges are validated; 60M is limited to standard channels.
  6. Auto-start (optional): If legacy autostart flags are enabled, selecting Digi mode can auto-launch FLDigi/FLMsg/FLAmp.
  7. Time toggle: Use the "Showing: Local/UTC" button to change what you see. The schedule is stored in UTC either way.
  8. QSY controls: The QSY dropdown and button under the time bar are shared across tabs. Use them for a manual QSY and a 30-minute scheduler pause. See QSY / Suspend.
  9. Save or Export: Save HF Schedule writes to the app database and updates the planner. Export HF Schedule writes JSON.
  10. Delete Selected: Use the left checkbox or select a row to enable Delete.

Back to Operating Groups | Back to Quick Start

Net Schedule Tab

  1. Purpose: Net Schedule is used by FLDigi NCS, JS8 NCS, and the planner to show upcoming nets.
  2. Add a row: Choose Day, Recurrence (Weekly / Bi-Weekly / Ad Hoc), Group Name, Band, Mode, VFO, Start/End, and Net Name. If Start is later than End, the net spans overnight into the next day.
  3. Bi-Weekly prompt: When saving a Bi-Weekly net, you will be asked whether the next occurrence starts this week or the week after.
  4. Early (min): Expands the net window earlier for rig changes and net control auto-fill. It does not change the displayed net time.
  5. Auto-Tune: Runs rig tune when this row becomes active (if supported).
  6. Net Name usage: Net names appear in FLDigi NCS and JS8 NCS auto-complete and in the Next Scheduled Net banner.
  7. Time toggle: "Showing: Local/UTC" changes view only; rows are stored in UTC.
  8. Frequency validation: Band and frequency are validated; 60M is limited to standard channels.
  9. Auto-start (optional): If legacy autostart flags are enabled, Digi mode can auto-launch FLDigi/FLMsg/FLAmp.
  10. Save / Import / Export: Save writes to settings and the net schedule database. Export creates a UTC JSON file; Import reads UTC and defaults VFO to A and Auto-Tune off.
  11. Delete Selected: Use the left checkbox or select a row to enable Delete.

Scheduler Engine

  • Priority: Active net schedule rows take priority; otherwise the HF schedule is used.
  • Controller: Frequency changes are sent via the controller selected in Settings > Operation Settings. Manual mode never sends rig commands.
  • Safety: The scheduler skips changes while FLRig PTT is active or when JS8Call/VarAC is busy.
  • QSY pause: Any QSY starts a 30-minute pause that suppresses schedule-driven changes. This pause is shared across Daily Schedule, FLDigi NCS, and JS8 NCS.
  • Use Scheduler: If the scheduler is disabled in Settings, no schedule-driven changes are sent and QSY controls are disabled.

Frequency Planner Tab

  1. Purpose: A read-only view of your HF and Net schedules in a 24-hour grid. It updates when schedules are saved and whenever you open the tab.
  2. Time toggle: Switch between Local and UTC. Column labels show the timezone abbreviation.
  3. HF vs Net display: If a net is active in a slot, the net name is shown. Otherwise the band label from the HF schedule is shown.
  4. Highlights: Nets within the next 24 hours and the currently active net are highlighted.
  5. Band colors: The band legend above the grid matches the HF schedule colors.

Back to Quick Start

QSY / Suspend (shared behavior)

  • Where it appears: Daily Schedule, FLDigi NCS, and JS8 NCS.
  • Select Frequency: The dropdown is built from Operating Groups. If duplicates exist, Auto-Tune wins.
  • QSY button: Applies the change immediately, triggers Auto-Tune if marked, and pauses the scheduler for 30 minutes. The button shows the remaining pause time.
  • Resume prompt: When 5 minutes remain, you can extend the pause by another 30 minutes.
  • Disabled states: QSY is disabled if the scheduler is off or if the selected frequency already matches the current scheduler frequency.

4. Net Control Tabs

FLDigi NCS Tab

  1. Check the header first: UTC/Local clocks show real-time timekeeping. The "Next Scheduled Net" banner summarizes the next net from Net Schedule and also shows the current band; if scheduling is paused it shows the resume time.
  2. Set Role and Net Name: Choose NCS/ANCS/JOINER. Role controls whether your own line gets a trailing / NCS or / ANCS when you start the net. Net Name is required; it auto-fills with the next scheduled net summary, but you can type any name.
  3. Optionally QSY before or during the net: Pick a frequency from the dropdown (built from Operating Groups) and click QSY. This changes frequency and pauses scheduling for 30 minutes; the button becomes a resume toggle and shows the remaining pause time. A 5-minute warning lets you extend the pause by 30 minutes. QSY is disabled if the scheduler is off or the selected frequency matches the current scheduler frequency.
  4. Start Ad Hoc Net (optional): Click Ad Hoc Net to create a timestamped net name and immediately start the net. If a name is already entered you will be asked to replace it. Ad Hoc is disabled while a net is running.
  5. Use Operator Lookup/Add for fast check-ins: Type callsign/name/state to search operator history. If there is a single match, press Tab or Enter to auto-fill the full line; pressing Tab/Enter again moves focus to Add to Main, then to Add to New/Late. You can add extra notes after the state, and they are kept when you insert the line. The Add buttons only highlight when callsign, name, and state are present.
  6. Manage the check-in panes: Main Check-in Log is your primary list; New/Late is for late arrivals. Both panes are editable. Copy copies the entire pane to the clipboard and highlights when content exists.
  7. Save Check-ins: Writes both panes to the check-in files configured in Settings > Messages & Files and refreshes operator history views.
  8. Merge Check-ins: Moves New/Late entries into Main (normalized to CALL / Name / ST) and clears New/Late. This does not prompt for confirmation.
  9. End Net: Confirms before ending, saves files, and imports valid Main lines into operator history (callsign/state uppercased, name capitalized). If the Main file is empty you can choose to end without importing. If a scheduled frequency change occurs and scheduling is not paused, the net auto-ends at the change time.
  10. Check-in files location: Configure in Settings > Messages & Files as FLDigi Check-in File Path. If left blank, a safe temp folder is used. Files are created on Save Settings and on net start: main_checkins.txt and new-late_checkins.txt. The check-in files are cleared when a new net is started.

JS8 NCS Tab

  1. Before you start: Configure your callsign and JS8Call DIRECTED.TXT path in Settings > JS8Call Settings. JS8 NCS will not start without a callsign, a net name, a group, and DIRECTED.TXT.
  2. Set Role, Net Name, and Refresh: Choose NCS or ANCS, type a Net Name, and set the refresh interval (seconds). The Net Name will auto-fill if a net is within the next 20 minutes (including early check-in time).
  3. Set Group: Enter a group (with or without "@") and click Set Group. This is required to start a net and is used for group messages like NET CONCLUDED.
  4. Pick a Spotter form (optional): Choose a form from the dropdown and click Set Expect Query. Forms come from the JS8Spotter folder in Settings. If no forms exist, spotter actions stay disabled.
  5. Choose a check-in filter: Default is F!103 / F!104 (spotter check-ins). You can also accept any spotter form or all callsigns.
  6. Check-in table: Columns include callsign, name, state, grid, region, mode, SNR, DT, offset, and status.
  7. Start Net: Clears the table and begins monitoring. The Start button grays out, ACK buttons enable, and Ad Hoc is disabled.
  8. ACK check-ins: ACK GROUP sends a group ACK for NEW entries using short codes; ACK CALLSIGN ACKs the selected row. Status updates to ACKED.
  9. Status updates: When a station replies with the expected spotter form, the Status column shows that F!### code.
  10. Spotter queries: E? GROUP sends the selected form to the group; E? Callsign sends it to the selected row.
  11. Save Checkins: Records one check-in per callsign for this net and updates Operator History. This does not write a file; the net log is written on End Net.
  12. QSY: Use the shared QSY control to change frequency and pause the scheduler. See QSY / Suspend.
  13. End Net: You can send a NET CONCLUDED group message, end without TX, or cancel. Ending writes a net log file to a net_logs folder next to DIRECTED.TXT and clears the table.
  14. Announcements (F!106): When no net is active, a complete F!106 announcement triggers a popup alert.

5. Other Tabs

Messages Tab

  1. Connect your folders first: Paths are configured in Settings > Messages & Files. If those paths are empty, the Messages list will be limited.
  2. Scan every: Controls how often file-based folders (VarAC/FLMSG/FLAMP) are rescanned. JS8 inbox polling runs on its own timer.
  3. Refresh Now: Forces an immediate scan and table refresh.
  4. Pending JS8 MSGs: The table shows pending message IDs; click GET to send a JS8 QUERY MSG, or Mark Retrieved to clear it. If Mark JS8Call MSG Retrieved is enabled in Settings, the JS8 inbox row is also marked READ.
  5. Messages table: Click View to open the message in the reader. File-based rows also show Delete (moves the file to your recycle bin/trash). JS8 messages are not deleted.
  6. Reader panel: The right-hand viewer shows the selected message and keeps the list stable while you read.
  7. Filters and sorting: Filter by type/status/from/to and a free-text search. Use Clear Filters to reset. Click column headers to sort.
  8. Export to PDF: Exports the currently viewed file-based message to PDF.
  9. Spotter decoding: If JS8Spotter forms are configured, F!### messages are decoded into readable answers in the viewer.

Operators Tab

  1. What this is: A live history of operators, built from net check-ins, JS8 traffic ingestion, and manual edits.
  2. Search and filter: Use the search box to filter any column, or filter by Group/Untrusted.
  3. Trusted flag: Untrusted rows are highlighted so you can review them quickly.
  4. Import CSV: Callsign is required. Optional columns include name, state, grid, group1-3, group_role, and dates.
  5. Add / Edit / Delete: Use the checkbox column to select rows. Edit supports bulk Trusted updates when multiple rows are selected.
  6. Select All: Checks every row so you can apply bulk actions.
  7. Map integration: This table powers the Map tab, including grids and states.

Back to Quick Start

Peer Schedules Tab

  1. Import Schedule: Load a peer HF schedule JSON (UTC) and store it locally.
  2. Refresh: Reloads the list from the database after imports or deletes.
  3. Filter view: Filter by callsign, FEMA region, group, or search text.
  4. Delete Schedule: Choose a callsign from the delete dropdown to remove that operator's imported schedule.
  5. Clear All: Removes all imported peer schedules.

Map Tab

  1. Map view: Requires Qt WebEngine. If it is missing, a message will say the map is disabled.
  2. Layers (sidebar): The layer controls appear in the left sidebar only when the Map tab is active. Use them to show Callsigns, States, Cities, Grids, and Regions. City labels respect the population threshold dropdown.
  3. JS8 link controls: Choose link mode (My Station, All, Bidirectional, One-way, Relays, or a region/group), filter by band/frequency, and set recency (3h, 6h, 24h, etc). Region and group choices come from Operator History.
  4. Relays mode: Use the "Paths to" field to choose a target callsign for relay path highlighting.
  5. Auto-refresh: The map can auto-refresh JS8 links on a timer. Use Refresh Links to force an update.
  6. Data sources: Operator locations come from Operator History and your Settings grid; link lines come from JS8 DIRECTED/ALL logs and live JS8 RX. If links are empty, run Load JS8 Traffic in Settings > JS8Call Settings.

Logs Tab

  1. Refresh: Reloads the log view. The tab also auto-refreshes.
  2. Clear: Clears the on-screen view (does not delete the log file).
  3. Search: Prompts for a keyword and shows matching lines.
  4. Open Log: Opens the log file in your OS default viewer.
  5. Level: Filters what you see and sets the global log level (Disabled, Error, Warning, Info, Debug, All).
  6. Font size: Adjust the font size to make logs easier to read.

Help Tab

  • Shows this guide. The left pane is a Table of Contents built from the H1-H3 headings; click to jump to a section.

6. Troubleshooting and Tips

  • Scheduler not changing frequency: Verify Use Scheduler is on, the pause timer has expired, and Operating Groups include valid band/mode/frequency.
  • JS8 NCS will not start: Check that callsign, Net Name, Group, and DIRECTED.TXT are set in Settings.
  • Messages list is empty: Confirm Message Paths in Settings and click Refresh Now.
  • Map shows no links: Use Load JS8 Traffic in Settings and confirm DIRECTED.TXT is valid.
  • Logs too large: Keep level at Disabled or Info for daily use; raise to Debug or All only for troubleshooting.
